# ShegerFlix 🇪🇹

> Ethiopia's Home for Stories.

ShegerFlix is a full-stack Netflix-style movie and series browsing platform focused on Ethiopian content.

Users can browse, search, and filter titles, view title details, manage a personal watch list, and track their watch history. The project also includes authentication and an admin dashboard for managing titles and users.

## ✨ Features

- 🎬 Browse movies and series
- 🔎 Search and filter titles
- 👤 User registration and login
- 🔐 JWT authentication
- ❤️ Personal watch list
- ▶️ Watch history and progress tracking
- 🛠️ Admin dashboard
- 📱 Responsive design

## 🛠️ Tech Stack

**Frontend**

- React
- React Router
- Tailwind CSS
- Axios
- Vite

**Backend**

- Node.js
- Express.js
- REST API

**Database**

- MySQL

**Authentication**

- JWT
